# Security Policy

## Supported versions

Security fixes go into the latest release of the `frogbot` package and the `@frogbotai/*` and `create-frogbot-app` packages released with it. Older versions don't get fixes, so upgrade to the latest release to receive them.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the repository's [Security tab](https://github.com/frogbotai/frogbot/security) and choose **Report a vulnerability**. Please don't open a public issue, pull request or Discord thread for a vulnerability.

A useful report says:

- the package and version affected,
- what an attacker can do, and what they need first (an account, a role, network access),
- the steps or a minimal project that reproduces it.

## What happens after you report

1. We acknowledge the report within 3 business days.
2. We confirm or rule out the issue and tell you which, with our reasoning.
3. For a confirmed issue, we prepare the fix in a private fork, release it, then publish a GitHub Security Advisory that credits you unless you'd rather stay anonymous.
4. We keep you updated in the advisory thread until it's published.

Please keep the details private until the advisory is published. We don't offer a bug bounty.
