# @frogbotai/ui

Reusable themed components for FrogBot interfaces.

Import primitives and composites from `@frogbotai/ui`, and load `@frogbotai/ui/styles.css` once in the application. Components use the `data-fb-ui` theme tokens and support light and dark themes without a styling framework.

See [CONTRIBUTING.md](./CONTRIBUTING.md) for component organization, styling, dependency, and Firmware-port conventions.
