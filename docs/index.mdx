**Define agents, tools, integrations, and your entire data layer in one config — FrogBot turns it into a sleek production UI, database, and backend.**

FrogBot is the fastest way to vibe code production-grade applications in the AI era.

## Why AI needs FrogBot

Prompting an AI from scratch produces 15,000 lines of fragile code for auth, database tables, permissions, and background queues. FrogBot gives coding agents (Claude Code, Cursor, Codex, OpenCode) an established, declarative foundation. So your agent writes one `frogbot.config.ts` instead of rebuilding backend plumbing.

Every FrogBot app is a standard MIT-licensed TypeScript codebase you own forever. Run it anywhere Docker or Node.js runs, or put it online on [Dojo](/plugins/dojo) in one command with [`npx frogbot deploy`](/deployment/overview).

## Start here

Paste this prompt into Claude Code, Cursor, Codex, or OpenCode to scaffold and boot a FrogBot app with the [FrogBot coding-agent skill](/skills/coding-agents):

<StarterPrompt />

Prefer the terminal? Scaffold an app directly with the CLI:

```bash
npx create-frogbot-app@latest my-app
cd my-app
npm run dev
```

The CLI asks for an AI provider and its key. Leave the key blank to add it to `.env` later. Open [http://localhost:3000](http://localhost:3000) to create your first admin user, explore your collections, and start a chat. See [Installation](/getting-started/installation) for every setup flag.

## What's in the box

| Building block | What you get out of the box |
| --- | --- |
| **[Data layer & Admin UI](/configuration/collections)** | Collections, fields, auth, access control, versions, drafts, and hooks, with instant Table, Kanban board, and Calendar views. |
| **[Config-first AI agents](/agents/overview)** | Typed Zod tool schemas, per-request access control functions, server-owned chat history, and automatic JSON and SSE streaming endpoints. |
| **[Embeddable MIT AI gateway](/gateway/overview)** | Route to OpenAI, Anthropic, Google, and 30+ more providers through a single self-hosted `provider/model` catalog. |
| **[40+ OAuth pieces & channels](/pieces/overview)** | Connect Slack, Discord, Linear, GitHub, Teams, Telegram, Gmail, Stripe, Notion, Xero, and more with managed OAuth and channel approvals. |
| **[Durable jobs & schedules](/jobs-queue/overview)** | Background queues, cron schedules, automatic retries, and dedicated workers backed by your database. |
| **[End-to-end TypeScript](/typescript/generating-types)** | Single-command type generation (`frogbot generate:types`) across your collections, agents, and pieces. |
| **[Swappable adapters & Dojo](/deployment/overview)** | Swap SQLite, Postgres, or MongoDB, S3/R2/GCS storage, and Redis KV anytime, or deploy in one command with `npx frogbot deploy`. |
