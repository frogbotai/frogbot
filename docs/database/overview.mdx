FrogBot is database agnostic. You bring your own database and own your data. FrogBot interacts with your database through a database adapter configured on the `db` property in [`frogbot.config.ts`](/configuration/overview):

```ts
import { sqliteAdapter } from '@frogbotai/db-sqlite'
import { buildConfig } from 'frogbot'

export default buildConfig({
  // ...
  db: sqliteAdapter({
    client: {
      url: process.env.DATABASE_URL || 'file:./frogbot.db',
    },
  }),
})
```

<Warning>
  Install your chosen database adapter package alongside `frogbot` in your project.
</Warning>

## Supported adapters

| Adapter | Database | Guide |
| --- | --- | --- |
| `@frogbotai/db-sqlite` | SQLite & LibSQL (default in `create-frogbot-app`) | [SQLite](/database/sqlite) |
| `@frogbotai/db-postgres` | PostgreSQL | [Postgres](/database/postgres) |
| `@frogbotai/db-mongodb` | MongoDB | [MongoDB](/database/mongodb) |
| `@frogbotai/db-vercel-postgres` | Vercel Postgres | [Postgres](/database/postgres#vercel-postgres-adapter) |
| `@frogbotai/db-d1-sqlite` | Cloudflare D1 | [SQLite & D1](/database/sqlite#d1-collection-search) |

## Collection search status

You can store supplied vectors on ordinary records using a [vector field](/fields/vector) without a search index. Native ranked search is separate: the [collection search API](/search/overview) runs only on adapters that implement it.

| Adapter | Collection search today |
| --- | --- |
| [Postgres and Vercel Postgres](/database/postgres#collection-search) | Lexical, vector, and hybrid |
| [SQLite and LibSQL](/database/sqlite#collection-search) | Lexical, vector, and hybrid |
| [MongoDB](/database/mongodb#collection-search) | Lexical, vector, and hybrid on deployments with a search process (Atlas or `mongot`) |
| [Cloudflare D1](/database/sqlite#d1-collection-search) | Lexical (vector and hybrid are an engine gap) |

Setup fails in these cases:

| Case | Error |
| --- | --- |
| An index with `vector` on Cloudflare D1, which has no native vector search. | `engine-gap` |
| Any configured collection `search` index, including lexical-only, on an adapter without search. The error identifies the collection, index, and mode. | `not-implemented` |
| A search index on a MongoDB deployment without a search process. | `missing-prerequisite` |

With no search index configured, setup does not emit a search capability report.

## Selecting a database

### SQLite (`@frogbotai/db-sqlite`)

SQLite is the default in `create-frogbot-app`. It stores your entire database in a single local file (`file:./frogbot.db`) or in a remote LibSQL or Turso database, so you run no database server locally.

- **Dojo.** When you deploy to [Dojo](/plugins/dojo), `npx frogbot deploy` can bring your local SQLite data along on the first deploy.
- **Google Cloud, AWS, and Azure.** Point `DATABASE_URL` at a hosted database instead. Their disks are wiped on restart, so [`frogbot deploy`](/deployment/overview) refuses a local file.

```ts
import { sqliteAdapter } from '@frogbotai/db-sqlite'
import { buildConfig } from 'frogbot'

export default buildConfig({
  db: sqliteAdapter({
    client: { url: process.env.DATABASE_URL || 'file:./frogbot.db' },
  }),
})
```

### Postgres (`@frogbotai/db-postgres`)

Postgres is a strong fit when you want strict relational schemas, foreign-key constraints, and multi-instance horizontal scaling backed by Drizzle ORM and [Migrations](/database/migrations).

```ts
import { postgresAdapter } from '@frogbotai/db-postgres'
import { buildConfig } from 'frogbot'

export default buildConfig({
  db: postgresAdapter({
    pool: { connectionString: process.env.DATABASE_URL },
  }),
})
```

### MongoDB (`@frogbotai/db-mongodb`)

Each record in MongoDB is stored as a document whose shape mirrors your collection fields, making it well-suited for deeply nested arrays, blocks, or rapid schema evolution without DDL migrations.

```ts
import { mongooseAdapter } from '@frogbotai/db-mongodb'
import { buildConfig } from 'frogbot'

export default buildConfig({
  db: mongooseAdapter({
    url: process.env.DATABASE_URL || false,
  }),
})
```
