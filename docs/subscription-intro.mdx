title: "Intro"
description: "One subscription for all AI agents and models"
---

Frogbot is a unified AI subscription that works with any coding agent and any model. One API key gives you access to chat, embeddings, audio, image generation, and reranking endpoints across Anthropic, OpenAI, Google, and specialized providers like ElevenLabs and Voyage on subscription pricing.

---

## Base URL

```text
https://app.frogbot.ai/api
```

## Authentication

Include your API key in the request headers.

```bash
Authorization: Bearer YOUR_API_KEY
```

Or use the `x-frogbot-api-key` header:

```bash
x-frogbot-api-key: YOUR_API_KEY
```
