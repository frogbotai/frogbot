Frogbot works with any coding agent and supported model. One API key gives you access to chat, embeddings, audio, image generation, and reranking endpoints, with usage billed at exact provider cost from your USD balance.

---

## Base URL

```text
https://app.frogbot.ai/api
```

## Authentication

Include your API key in the request headers.

```bash
Authorization: Bearer YOUR_API_KEY
```

Or use the `x-frogbot-api-key` header:

```bash
x-frogbot-api-key: YOUR_API_KEY
```
