Codex CLI can talk to Frogbot by setting a custom base URL.
This lets you use models from multiple providers with one key.

## Install

Install the Codex CLI.

```bash
npm install -g @openai/codex
```

Confirm it’s on your PATH.

```bash
codex --version
```

---

## Configure

Create or edit `~/.codex/config.toml`.
Set a provider that points to Frogbot.

```toml
[model_providers.frogbot]
name = "Frogbot"
base_url = "https://app.frogbot.ai/api/v1"
env_key = "FROGBOT_API_KEY"

[profiles.frogbot]
model_provider = "frogbot"
model = "gpt-4o"
```

Export your API key in your shell.

```bash
export FROGBOT_API_KEY="fw_api_..."
```

---

## Pick a model

Choose a model ID from the [models list](/).
You can set it in the profile or pass `--model` per run.

---

## Run

Use the Frogbot profile for any session.

```bash
codex --profile frogbot
```

Override the model when you need to.

```bash
codex --profile frogbot --model "claude-opus-4-5"
```

---

## Troubleshoot

If you get a 401, double-check the `FROGBOT_API_KEY` value.
If you get a 404, make sure `base_url` ends with `/v1`.
