Everything you do in Dojo's site, you can do from the terminal with `frogbot deploy` and `frogbot dojo`. They come with the [Dojo plugin](/plugins/dojo), which apps made with `create-frogbot-app` already list. `npx frogbot dojo` needs such an app; in any other folder, including on a fresh machine, run the same commands as `npx @frogbotai/plugin-dojo`:

```bash
npx @frogbotai/plugin-dojo login
npx @frogbotai/plugin-dojo apps list
```

## Every day

In a folder you deployed, the commands act on its app, so you don't name it:

```bash
npx frogbot deploy                           # build and deploy this folder, print its URL
npx frogbot dojo status                      # address, live or not, and the last deploy
npx frogbot dojo logs --follow               # runtime log, or the build log when the last deploy failed
npx frogbot dojo open                        # print the address and open it
npx frogbot dojo rollback                    # back to the previous live version
npx frogbot dojo env set STRIPE_SECRET_KEY=sk_live_...
```

`frogbot deploy` writes the app's id to `.frogbot/app.json`, which is how the others find it. Name an app to act on another one: `npx frogbot dojo status deals`. Every command below that takes `<app>` also leaves it out in that folder.

## Commands

The daily commands come first in `frogbot dojo --help`. The rest are grouped by noun: `workspaces`, `members`, `projects`, `apps`, `handovers`, `deployments`, `git`, `env`, `domains`, `sharing`, `keys` and `billing`. The full table, with every flag, is in the [Dojo plugin reference](/plugins/dojo#commands). `frogbot dojo --help`, `frogbot dojo apps --help` and `frogbot dojo apps delete --help` print the same lists.

## For scripts and coding agents

- Add `--json` to any command to get one JSON value on stdout and nothing else.
- `frogbot dojo --help --json` lists every command, verb and flag, with its usage, as one JSON value.
- Set `FROGBOT_DOJO_TOKEN` to an [API key](/dojo/api-keys) so nothing waits for a browser.
- Commands that delete or replace something ask first; pass `--yes` when there's no terminal.

[Scripts and agents](/plugins/dojo#scripts-and-agents) covers exit codes and refusals.

Agents that need a browser of their own, rather than Dojo, can use the separate [Browser Agent MCP](/browser-mcp).
