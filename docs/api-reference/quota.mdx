Check the USD balance available for AI usage.

---

## Authenticate

```bash
curl https://app.frogbot.ai/api/v1/quota \
  -H "Authorization: Bearer $FROGBOT_API_KEY"
```

---

## Read fields

| Field | Type | Description |
|-------|------|-------------|
| `balanceUSD` | number | Available balance in US dollars |

---

## View examples

```json 200
{
  "balanceUSD": 26.25
}
```

```json 401
{
  "error": "Unauthorized"
}
```

---

## Understand results

`balanceUSD` includes subscription payments and any funds you add. AI usage reduces it at the provider's exact USD cost.
