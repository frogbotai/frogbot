## Authenticate

Use an API key in the `Authorization` header.

```bash
curl https://app.frogbot.ai/api/v1/models \
  -H "Authorization: Bearer $FROGBOT_API_KEY"
```

## Understand response

Returns an OpenAI-compatible list object.
Each entry is a supported model object.

<ResponseField name="object" type="string">
  Always `list`.
</ResponseField>

<ResponseField name="data" type="array">
  Array of model objects.

  <Expandable title="Model object">
    <ResponseField name="id" type="string">
      Provider-prefixed model ID like `openai/gpt-4o-mini`.
    </ResponseField>

    <ResponseField name="object" type="string">
      Typically `model`.
    </ResponseField>

    <ResponseField name="created" type="integer">
      Unix timestamp, if provided by upstream.
    </ResponseField>

    <ResponseField name="owned_by" type="string">
      Provider name like `openai`.
    </ResponseField>

    <ResponseField name="provider" type="string">
      Provider name, if included.
    </ResponseField>

    <ResponseField name="created_at" type="string">
      ISO timestamp, if included.
    </ResponseField>

    <ResponseField name="provider_info" type="object">
      Provider metadata like status, if included.
    </ResponseField>

    <ResponseField name="..." type="any">
      Additional fields may be present.
    </ResponseField>
  </Expandable>
</ResponseField>

## See example

```json
{
  "object": "list",
  "data": [
    {
      "id": "openai/gpt-4o-mini",
      "object": "model",
      "created": 1735689600,
      "owned_by": "openai",
      "provider_info": {
        "status": "enabled"
      }
    }
  ]
}
```

## Handle errors

`401` means the API key is missing or invalid.
`429` means you hit a usage or plan limit.
