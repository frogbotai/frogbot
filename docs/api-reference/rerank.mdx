---
title: "Rerank"
description: "Rerank documents by relevance to a query"
api: "POST https://app.frogbot.ai/api/v1/rerank"
---

Rerank a list of documents by relevance to a query. Returns documents sorted by relevance score.

---

## Authenticate

Use an API key in the `Authorization` header.

```bash
curl https://app.frogbot.ai/api/v1/rerank \
  -H "Authorization: Bearer $FROGBOT_API_KEY"
```

---

## Request body

<ParamField body="model" type="string" required>
  Reranking model ID to use. See [available rerank models](/api-reference/models#rerank) for the full list.

  Examples: `rerank-2.5`, `rerank-2.5-lite`
</ParamField>

<ParamField body="query" type="string" required>
  The search query to rank documents against.
</ParamField>

<ParamField body="documents" type="array" required>
  List of documents to rerank. Pass an array of strings or objects with a `text` field.

```json
["First document text", "Second document text", "Third document text"]
```

</ParamField>

<ParamField body="top_n" type="integer">
  Number of top results to return. Defaults to the total number of documents.
</ParamField>

<ParamField body="return_documents" type="boolean" default="false">
  Whether to include the document text in the response.
</ParamField>

---

## Response

<ResponseField name="id" type="string">
  Unique identifier for the rerank request.
</ResponseField>

<ResponseField name="results" type="array">
  Reranked documents sorted by relevance score descending.

  <Expandable title="Result object">
    <ResponseField name="index" type="integer">
      Original index of the document in the input array.
    </ResponseField>
    <ResponseField name="relevance_score" type="number">
      Relevance score between 0 and 1. Higher is more relevant.
    </ResponseField>
    <ResponseField name="document" type="object">
      The document text, if `return_documents` is `true`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="usage" type="object">
  Token usage statistics.

  <Expandable title="Usage object">
    <ResponseField name="total_tokens" type="integer">
      Total tokens processed, calculated as query tokens × number of documents + sum of document tokens.
    </ResponseField>
  </Expandable>
</ResponseField>

## Examples

<CodeGroup>
```bash curl
curl https://app.frogbot.ai/api/v1/rerank \
  -H "Authorization: Bearer $FROGBOT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "rerank-2.5",
    "query": "What is the capital of France?",
    "documents": [
      "Paris is the capital of France.",
      "Berlin is the capital of Germany.",
      "France is a country in Western Europe."
    ],
    "top_n": 2
  }'
```

```python Python
import voyageai

# Or use any HTTP client pointed at the Frogbot base URL
import requests

response = requests.post(
    "https://app.frogbot.ai/api/v1/rerank",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    json={
        "model": "rerank-2.5",
        "query": "What is the capital of France?",
        "documents": [
            "Paris is the capital of France.",
            "Berlin is the capital of Germany.",
            "France is a country in Western Europe.",
        ],
        "top_n": 2,
        "return_documents": True,
    }
)

print(response.json())
```
