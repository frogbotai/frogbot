---
title: "Import and export"
description: "Add Payload import and export workflows to FrogBot collections."
---

## Install

```bash
pnpm add @frogbotai/plugin-import-export
```

## Configure

```ts
import { importExportPlugin } from '@frogbotai/plugin-import-export'

plugins: [importExportPlugin({ collections: [{ slug: 'posts' }] })]
```

The adapter preserves Payload's collection selection, import and export controls, limits, lifecycle hooks, and collection overrides. It adds the upstream admin provider, import and export collections, and jobs without replacing existing app config.
