The Number field stores numeric values and supports numeric range validation.

```ts
import type { Field } from 'frogbot'

export const Price: Field = {
  name: 'price',
  type: 'number',
  min: 0,
  required: true,
  admin: { step: 0.01 },
}
```

## Config options

| Option | Description |
| --- | --- |
| **`name`** * | Stored property name. See [field names](/fields/overview#field-names). |
| **`label`** | Admin-panel label. |
| **`min`** | Minimum accepted value. |
| **`max`** | Maximum accepted value. |
| **`hasMany`** | Stores an ordered array of numbers. |
| **`minRows`** | Minimum entries when `hasMany` is `true`. |
| **`maxRows`** | Maximum entries when `hasMany` is `true`. |
| **`unique`** | Creates a unique database index. |
| **`index`** | Creates a database index. |
| **`validate`** | Custom [validation](/fields/overview#validation). |
| **`saveToJWT`** | Includes a top-level auth field in the user token. |
| **`hooks`** | [Field hooks](/hooks/fields). |
| **`access`** | [Field access control](/access-control/fields). |
| **`hidden`** | Hides the field while retaining stored data. |
| **`defaultValue`** | Initial [field value](/fields/overview#default-values). |
| **`localized`** | Stores one value per locale. |
| **`required`** | Requires a value. |
| **`admin`** | Admin-panel settings. |
| **`custom`** | Extension metadata. |
| **`typescriptSchema`** | Type-generation JSON Schema override. |
| **`virtual`** | Omits database storage or links a relationship path. |

\*_An asterisk denotes a required option._

## Admin options

Number fields support the standard [field admin options](/fields/overview#admin-options), plus these options:

| Option | Description |
| --- | --- |
| **`step`** | Amount used by browser controls to increment or decrement the value. |
| **`placeholder`** | Placeholder text shown in the input. |
| **`autoComplete`** | Value used for browser autocomplete. |

## Example

```ts
import type { CollectionConfig } from 'frogbot'

export const Products: CollectionConfig = {
  slug: 'products',
  fields: [
    {
      name: 'price',
      type: 'number',
      min: 0,
      required: true,
      admin: {
        placeholder: '0.00',
        step: 0.01,
      },
    },
  ],
}
```

## Custom components

### Field

#### Server component

```tsx
import { NumberField } from '@frogbotai/ui'
import type { NumberFieldServerComponent } from 'frogbot'

export const CustomNumberServer: NumberFieldServerComponent = (props) => (
  <NumberField
    field={props.clientField}
    path={props.path}
    permissions={props.permissions}
    schemaPath={props.schemaPath}
  />
)
```

#### Client component

```tsx
'use client'

import { NumberField } from '@frogbotai/ui'
import type { NumberFieldClientComponent } from 'frogbot'

export const CustomNumberClient: NumberFieldClientComponent = (props) => <NumberField {...props} />
```

### Label

#### Server component

```tsx
import { FieldLabel } from '@frogbotai/ui'
import type { NumberFieldLabelServerComponent } from 'frogbot'

export const CustomNumberLabelServer: NumberFieldLabelServerComponent = ({ clientField, path }) => (
  <FieldLabel
    label={clientField.label || clientField.name}
    path={path}
    required={clientField.required}
  />
)
```

#### Client component

```tsx
'use client'

import { FieldLabel } from '@frogbotai/ui'
import type { NumberFieldLabelClientComponent } from 'frogbot'

export const CustomNumberLabelClient: NumberFieldLabelClientComponent = ({ field, path }) => (
  <FieldLabel label={field.label || field.name} path={path} required={field.required} />
)
```
