Root Components customize the Admin Panel across every route. Configure them through the root `admin.components` object.

```ts
import { buildConfig } from 'frogbot'

export default buildConfig({
  admin: {
    components: {
      actions: ['/components/HelpAction#HelpAction'],
      graphics: {
        Icon: '/components/BrandIcon#BrandIcon',
        Logo: '/components/BrandLogo#BrandLogo',
      },
    },
  },
  collections: [],
})
```

## Config Options

`admin.components` is the `RootAdminComponents` type. The other root `admin` options are listed in [Admin panel](/admin/overview#admin-options).

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `actions` | `FrogBotComponent[]` | `[]` | Components at the top right of the Admin Panel, in array order. |
| `beforeLogin` | `FrogBotComponent[]` | `[]` | Components before the login form's email and password fields. |
| `afterLogin` | `FrogBotComponent[]` | `[]` | Components after the login form's fields. When the user collection configures `auth.signIn`, FrogBot appends its sign-in buttons after your components. |
| `beforeNavLinks` | `FrogBotComponent[]` | `[]` | Components in the sidebar above the nav links. |
| `afterNavLinks` | `FrogBotComponent[]` | `[]` | Components in the sidebar below the nav links and sections. |
| `beforeBottomRail` | `FrogBotComponent[]` | `[]` | Components in the bottom sidebar rail, above Account and Settings. |
| `afterBottomRail` | `FrogBotComponent[]` | `[]` | Components in the bottom sidebar rail, below Account and Settings. |
| `beforeSidebarClose` | `FrogBotComponent[]` | `[]` | Components in the expanded sidebar header, left of the collapse button. |
| `beforeAccountMenu` | `FrogBotComponent[]` | `[]` | Account menu items above Settings. |
| `afterAccountMenu` | `FrogBotComponent[]` | `[]` | Account menu items below Settings. |
| `settingsMenu` | `FrogBotComponent[]` | `[]` | Account menu items after `afterAccountMenu`. |
| `logout` | `{ Button?: FrogBotComponent }` | Built-in Log out item | `Button` replaces the account menu's Log out item. |
| `chat` | `{ Chat?, Greeting?, AssistantMessageActions?, UserMessageActions? }` | Built-in chat components | Admin chat slots; each value is a `FrogBotComponent`. See [Chat](#chat). |
| `graphics` | `{ Icon?: FrogBotComponent, Logo?: FrogBotComponent }` | FrogBot head mark and wordmark | `Icon` replaces the compact mark in navigation. `Logo` replaces the full mark on the login page and the empty-chat greeting fallback. |
| `Nav` | `FrogBotComponent` | FrogBot sidebar | Replaces the complete sidebar navigation. See [Replace the sidebar](/admin/admin-navigation#replace-the-sidebar). |
| `navItems` | `NavItem[]` | `[]` | Links above your collections. See [Navigation item options](/admin/admin-navigation#navigation-item-options). |
| `navSections` | `FrogBotComponent[]` | `['@frogbotai/next#CollectionsSection']` | Sidebar sections below the links. Setting it replaces the default array. See [Configure sections](/admin/admin-navigation#configure-sections). |
| `providers` | `ProviderComponent[]` | `[]` | Components that wrap the Admin Panel and render `children`, outermost first. See [Custom Providers](./custom-providers). |
| `views` | `Record<string, AdminViewConfig>` | Built-in views, plus a `settings` view at `/settings` | Replaces built-in root views (`account`, `dashboard`, `settings`) or adds routes under any other key. See [View options](./custom-views#view-options). |

The `chat` slots are:

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `Chat` | `FrogBotComponent` | Built-in conversation surface | Replaces the complete chat surface. |
| `Greeting` | `FrogBotComponent` | Built-in greeting | Replaces the empty-chat greeting. It receives `avatar`, `logo`, `name`, and `userName`. |
| `AssistantMessageActions` | `FrogBotComponent` | Built-in actions | Replaces the controls under assistant messages. |
| `UserMessageActions` | `FrogBotComponent` | Built-in actions | Replaces the controls under user messages. |

See [Chat persistence](/chat/overview#customize-admin-chat-components) for the props each chat slot receives. See [Custom Providers](./custom-providers), [Custom Views](./custom-views), and [Dashboard](./dashboard) for those larger extension points.

## Components

### actions

Actions add controls to the Admin Panel header.

```tsx
import { Button } from '@frogbotai/ui'

export function HelpAction() {
  return <Button asChild><a href="/help">Help</a></Button>
}
```

### beforeLogin and afterLogin

Use `beforeLogin` and `afterLogin` to place content around the login fields:

```ts
components: {
  beforeLogin: ['/components/LoginNotice#LoginNotice'],
  afterLogin: ['/components/LoginHelp#LoginHelp'],
}
```

### Sidebar slots

Use the sidebar slots without replacing its built-in behavior:

```ts
components: {
  beforeSidebarClose: ['/components/WorkspaceName#WorkspaceName'],
  beforeNavLinks: ['/components/NavHeader#NavHeader'],
  afterNavLinks: ['/components/NavFooter#NavFooter'],
  beforeBottomRail: ['/components/SupportLink#SupportLink'],
  afterBottomRail: ['/components/Version#Version'],
}
```

### Account menu

Add items to the account menu or replace its Log out item:

```ts
components: {
  beforeAccountMenu: ['/components/WorkspaceSwitcher#WorkspaceSwitcher'],
  afterAccountMenu: ['/components/SupportLink#SupportLink'],
  logout: { Button: '/components/LogoutButton#LogoutButton' },
}
```

See [Customize the account menu](/admin/admin-navigation#customize-the-account-menu) for the item order and a sign-out example.

### Nav

`Nav` replaces the complete sidebar. Use `navItems` or `navSections` when you only need to change its contents.

```tsx
import Link from 'next/link'

export function CustomNav() {
  return <nav><Link href="/admin">Home</Link></nav>
}
```

```ts
components: {
  navItems: [
    { label: 'Operations', path: '/admin/operations' },
  ],
  navSections: ['/components/ProjectSection#ProjectSection'],
}
```

Navigation items are empty by default. Setting `navSections` replaces the default Collections section, so include `@frogbotai/next#CollectionsSection` to keep it. See [Admin navigation](/admin/admin-navigation) for New Chat and Recents examples.

### Chat

Chat slots customize the conversation, greeting, and message actions:

```ts
components: {
  chat: {
    Chat: '/components/ProjectChat#ProjectChat',
    Greeting: '/components/ProjectGreeting#ProjectGreeting',
    AssistantMessageActions: '/components/AssistantActions#AssistantActions',
    UserMessageActions: '/components/UserActions#UserActions',
  },
}
```

### graphics.Icon

`graphics.Icon` is the compact mark used in navigation.

```tsx
export function BrandIcon() {
  return <img src="/brand/icon.svg" alt="Acme" />
}
```

### graphics.Logo

`graphics.Logo` is the full mark used on the login page.

```tsx
export function BrandLogo() {
  return <img src="/brand/logo.svg" alt="Acme" />
}
```

## Component props

Type server components in these slots with `RootComponentServerProps`:

```tsx
import type { RootComponentServerProps } from 'frogbot'

export function SupportLink({ req, user }: RootComponentServerProps) {
  const agents = Object.keys(req?.frogbot.agents ?? {})

  return <a href="/support">Support ({user?.email}, {agents.length} agents)</a>
}
```

Root component props:

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `req` | `FrogBotRequest` | Optional | The current request. Use `req?.frogbot` to reach FrogBot. Not passed to login page components. |
| `user` | `UntypedUser` | Optional | The signed-in user, or `undefined` when nobody is signed in. Use `req.user` for authorization decisions. |
| `permissions` | `SanitizedPermissions` | Optional | The current user's collection and admin permissions. |
| `visibleEntities` | `VisibleEntities` | Optional | Slugs of the collections visible to the current user. |
| `i18n` | `I18nClient` | Required | Translation helpers and the current admin language. |
| `locale` | `Locale` | Optional | The current content locale when localization is enabled. |
| `params` | `Params` | Optional | Route parameters of the current admin page. |
| `searchParams` | `Params` | Optional | Query string parameters of the current admin page. |
| `viewType` | `ViewTypes` | Optional | The kind of view being rendered, such as `'list'` or `'document'`. |
| `documentSubViewType` | `DocumentSubViewTypes` | Optional | The document sub-view, such as `'default'` or `'versions'`, on document routes. |
| `id` | `string \| number` | Optional | Part of the shared type; the built-in root slots don't set it. |

`req` is optional:

- Sidebar, account menu, top bar, and custom `Nav` components receive `req`. Use `req?.frogbot` to reach FrogBot.
- Login page components (`beforeLogin`, `afterLogin`, and `graphics.Logo`) don't receive `req`. Use `getCachedFrogBot()` from `frogbot` instead.
