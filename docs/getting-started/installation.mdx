## Create an app

Scaffold a new FrogBot project with everything wired up:

```bash
npx create-frogbot-app my-agent-platform
```

The setup asks you to choose a database, an AI provider, and any coding agents that should receive the FrogBot skill. The blank template is selected automatically while it is the only available template. Your current package manager is detected; dependency installation and Git initialization are enabled by default.

For a non-interactive setup with the defaults, use `--yes`:

```bash
npx create-frogbot-app my-agent-platform --yes
```

The defaults create a Next.js app using SQLite and the free Zen AI provider. You can select another database with `--db sqlite`, `--db postgres`, or `--db mongodb`. Run `npx create-frogbot-app --help` to see the matching flags for every setup choice.

## Run the app

`create-frogbot-app` writes a `.env` file with a generated `FROGBOT_SECRET` and the connection string for your selected database. Add any requested provider credentials before starting the app.

```bash
cd my-agent-platform
npm run dev
```

Use the equivalent dev command if you selected pnpm, yarn, or bun. Then open [http://localhost:3000](http://localhost:3000). To change app behavior, edit `src/frogbot.config.ts`; see [Configuration](/configuration/overview) for the full schema.

## Software requirements

- Node.js 22 or newer
- npm, pnpm, yarn, or bun
- SQLite, PostgreSQL, or MongoDB — see [Database](/database/overview)
- Optional: an object store (S3, GCS, Azure, R2, Vercel Blob, or Uploadthing) — see [Configuration](/configuration/overview#storage)
