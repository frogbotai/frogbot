There are two ways to use Live Preview, depending on whether your front-end framework supports Server Components:

- [Server-side Live Preview (suggested)](/live-preview/server)
- [Client-side Live Preview](/live-preview/client)

<Note>
  Use server-side Live Preview when your framework supports Server Components. It is simpler to set up and requires less client-side work.
</Note>
