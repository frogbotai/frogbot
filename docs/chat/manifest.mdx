The chat manifest gives clients the runtime configuration they need before starting a conversation. Use it instead of hard-coding collection slugs or a transcription model.

For model requests from a FrogBot app, see the [embedded gateway HTTP endpoints](/ai/overview#call-over-http).

```bash
curl http://localhost:3000/api/frogbot \
  --header "Authorization: Bearer $FROGBOT_TOKEN"
```

An enabled chat configuration returns the resolved collection slugs and the agents available to the caller.

```json
{
  "ai": {
    "transcribe": { "model": "groq/whisper-large-v3" }
  },
  "chat": {
    "enabled": true,
    "chatsSlug": "conversations",
    "messagesSlug": "turns",
    "assetsSlug": "frogbot-chat-assets"
  },
  "files": { "slug": "files" },
  "agents": [
    {
      "slug": "support",
      "profile": {
        "name": "Ada",
        "avatar": "/agents/ada.png",
        "description": "Answers support questions."
      }
    }
  ]
}
```

When chat persistence is disabled, `chat` contains only `enabled`.

```json
{
  "ai": { "transcribe": false },
  "chat": { "enabled": false },
  "files": { "slug": "files" },
  "agents": []
}
```

| Field | Type | Description |
| --- | --- | --- |
| `ai.transcribe` | `{ model: string } \| false` | The first catalog transcription model from a configured provider, or `false` when there is none. The chat composer shows its microphone only when this is set. |
| `chat.enabled` | `boolean` | Whether chat persistence is enabled. |
| `chat.chatsSlug` | `string` | Slug of the chats collection. Present when `enabled` is `true`. |
| `chat.messagesSlug` | `string` | Slug of the messages collection. Present when `enabled` is `true`. |
| `chat.assetsSlug` | `string` | Slug of the chat assets collection that composer uploads go to. Present when `enabled` is `true`. |
| `files.slug` | `string` | Slug of the [files collection](/upload/files). |
| `agents[].slug` | `string` | Slug of an agent the caller may use. |
| `agents[].profile` | `{ name?: string; avatar?: string; description?: string }` | The agent's configured [profile](/agents/overview#profile-options), when it has one. |

## Agent manifest

`GET /api/agents` returns the agents the caller may use with their model choices. `ChatProvider` loads it alongside this manifest, and `AgentSelector` and `ModelSelector` read from it.

| Field | Type | Description |
| --- | --- | --- |
| `defaultAgent` | `string` | Slug of the first listed agent, or `''` when none is listed. |
| `agents[].slug` | `string` | Agent slug. |
| `agents[].label` | `string` | The profile `name`, or the slug. |
| `agents[].source` | `'config' \| 'collection'` | Where the agent is defined. Agents from `buildConfig` report `'config'`. |
| `agents[].defaultModel` | `string` | The model a request without `model` uses for this caller. |
| `agents[].models` | `string[]` | Models this caller may select, after the [user model policy](/ai/overview#user-model-and-budget-policy) is applied. |
| `agents[].names` | `Record<string, string>` | Display names for models that have one. Fall back to the ID for the rest. |
| `agents[].reasoning` | `Record<string, { key: string; label: string }[]>` | Reasoning options per model, for models that have any. |

Agents the caller can't access, and agents with no model the caller may use, are left out.

## Access behavior

The endpoint is available without authentication so a client can bootstrap before login. Each agent still runs its configured access rule for the current request. Anonymous callers see only agents that explicitly permit anonymous access, and an access rule that throws hides that agent.

The response includes `Cache-Control: private, no-store`. Do not retain it across users or sessions because agent visibility can change with authentication and custom access rules.

## Type the response

Import the public response contract when your client uses TypeScript.

```ts
import type { ManifestResponse } from 'frogbot'

const response = await fetch('/api/frogbot')
const manifest: ManifestResponse = await response.json()
```

The manifest includes each accessible agent's configured profile. It excludes app branding, upload targets, fixed internal collection slugs, and API-base metadata. Configure those app-level concerns in the client until FrogBot provides a dedicated public contract for them.
